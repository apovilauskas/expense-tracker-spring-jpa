# Expense Tracker

An expense tracking web application built with **Java** and **Spring Boot**.  
Users can add, view, categorize, and manage expenses through a clean server-rendered interface using **Thymeleaf**.

## Tech Stack

- **Java**
- **Spring Web** – MVC architecture and routing
- **Thymeleaf** – HTML template engine
- **Spring Data JPA** – database access layer
- **PostgreSQL Database** – secure database
- **Lombok** – reduces boilerplate code
- **Bean Validation** – input validation
